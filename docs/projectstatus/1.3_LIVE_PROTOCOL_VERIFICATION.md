## Official protocol evidence

Current official TallyHelp documentation verifies XML-over-HTTP POST, configurable ports, `text/xml`, the `ENVELOPE`/`HEADER`/`BODY` structure, and read-only `EXPORT`/`COLLECTION` requests. The documented `List of Ledgers` request is implemented and was sent to the local TallyPrime instance.

References:

- https://help.tallysolutions.com/pre-requisites-for-integrations/
- https://help.tallysolutions.com/xml-integration/
- https://help.tallysolutions.com/tally-prime-integration-using-json-1/

## Live result

The verified request returned HTTP 200 and XML with `<STATUS>1</STATUS>` from local TallyPrime. The response contained an empty collection and `CMPINFO` counts of zero, which indicates that no company was loaded/available for the requested ledger collection at test time. The parser was corrected to ignore summary `<LEDGER>0</LEDGER>` nodes rather than treating them as ledger records.

The CLI now reports a successful read-only XML connection diagnostic against the live local TallyPrime server.
