# Tally Prime Connector — Project Setup Report

Date: 2026-09-16

## Purpose

Created the first-milestone foundation for **Tally Prime Connector**: a local Windows/WPF application designed to connect to TallyPrime through supported integration mechanisms. The website is strictly a landing, download, documentation, and support site; it contains no Tally communication logic.

## Repository structure

Created the modular source, test, processing, TDL, installer, documentation, and script areas.

Current application directories are:

```
apps/
├── TallyPrimeConnector.App/     # WPF desktop application
└── TallyPrimeConnector.Site/    # Next.js website
```

The original requested nested `apps/desktop` and `apps/website` paths were superseded by the subsequent requested moves.

## Desktop foundation

Created `TallyPrimeConnector.sln` and these projects:

- `TallyPrimeConnector.Contracts` — normalized Tally DTOs, connection contracts, job models, and integration interfaces.
- `TallyPrimeConnector.Core` — service contracts, connection workflow, job-state transition logic, and user-facing exception categories.
- `TallyPrimeConnector.Tally` — mock company/collection/voucher providers and a safe XML/HTTP connection placeholder.
- `TallyPrimeConnector.Data` — EF Core SQLite `AppDbContext` with application-owned connection-profile and job entities.
- `TallyPrimeConnector.Processing` — two coordinated engines: C# Core Processing for normal accounting workflows and a Python Specialist Processing boundary for advanced analytical workloads. Phase 1.1 includes engine selection, runtime contracts, and a safe unavailable-runtime implementation.
- `TallyPrimeConnector.Excel` — ClosedXML ledger-per-sheet workbook exporter foundation.
- `TallyPrimeConnector.Infrastructure` — update-service abstraction implementation.
- `TallyPrimeConnector.App` — WPF MVVM navigation shell, dashboard, connection configuration inputs, and connection diagnostic display.

The WPF application uses DI, async commands, appsettings, Serilog configuration, and a LocalAppData log destination. No business logic is placed in WPF code-behind.

## Tally integration safety

Created supported-integration abstractions only:

- `ITallyConnection`
- `ITallyXmlClient`
- `ITallyOdbcClient`
- `ITallyTdlClient`
- `ITallyCompanyProvider`
- `ITallyCollectionProvider`
- `ITallyVoucherProvider`

No password bypassing, authentication bypassing, memory manipulation, direct Tally database access, or security workarounds were implemented. The live XML/HTTP behavior is intentionally not fabricated and is marked `TODO: VERIFY WITH TALLYPRIME` pending verified request/response documentation.

## Local/offline development

`MockTallyCompanyProvider`, `MockTallyCollectionProvider`, and `MockTallyVoucherProvider` allow desktop development without a live Tally installation. The real connection abstraction reports that live verification is unimplemented instead of falsely claiming a connection is available.

## Website foundation

Created a Next.js, TypeScript, and Tailwind website with:

- Home page and primary **Download Tally Prime Connector** CTA.
- Pages for features, how it works, download, documentation, support, privacy, and terms.

The temporary `app/[...page]` route is a valid Next.js catch-all route used to share page rendering. It can be replaced with individual folders if explicit page files are preferred.

## Tests created

Created xUnit projects for Core, Tally, Data, Processing, and Excel. Initial coverage includes:

- Decimal financial precision.
- Date-only handling.
- Debit and credit total calculation.
- Job state transitions.
- Invalid connection port validation.
- Mock Tally company retrieval.
- Excel worksheet name sanitization.

## Python specialist engine and installer

- `processing/python/` contains a first-class Python Specialist Processing Engine protocol skeleton and package metadata. It will be bundled and managed by the product; Python is not required for ordinary C# processing.
- `installer/README.md` reserves the installer architecture for WiX or MSIX, with application files intended for Program Files and user data for LocalAppData.
