## Supplied XML sample (not an export request)

The user supplied a large voucher XML sample whose header is `TALLYREQUEST=Import Data`, `REPORTNAME=All Masters`, and whose vouchers contain `ACTION="Create"`. This is an import/write payload, not a UI export and not safe to POST. It is therefore excluded from protocol verification.

It is still useful as a parser fixture: it confirms real fields including `DATE` (`20260901`), `GUID`, `MASTERID`, `VOUCHERTYPENAME`, `VOUCHERNUMBER`, `ALLLEDGERENTRIES.LIST`, `LEDGERNAME`, `ISDEEMEDPOSITIVE`, decimal `AMOUNT`, and the XML 1.0-invalid `&#4;` free-text marker. A regression test now verifies that sanitization preserves the date, amount, and debit/credit direction.
