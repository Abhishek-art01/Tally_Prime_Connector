# Phase status reports

Reports are organized by implementation phase, not by every individual prompt.

- The filename prefix is the phase number supplied in a main implementation prompt: for example, `01_` or `01.1_`.
- During a phase, update the applicable existing phase report rather than creating a new report for each follow-up instruction.
- Create a new report only when a new main prompt supplies a new phase number.

Each report records the phase scope, meaningful changes, verification performed, and blockers.
